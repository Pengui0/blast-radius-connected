Five questions every security scan leaves open

A list of advisories tells you what is wrong. It doesn’t tell you what to fix first. Blast Radius answers these from the dependency graph.

  • How does this vulnerability reach my app?

    Traces the shortest dependency path from your app to the advisory, so you can see exactly which package pulled it in.

  • Who is hurt if this package changes?

    Walks the graph backwards and lists every package that depends on it, directly or through others.

  • Which package is the real problem?

    Ranks packages by how much of the graph depends on them, and finds the direct dependency that carries the most risk of its own.

  • What are the fewest fixes that clear the most risk?

    Chooses upgrades one at a time by risk cleared. An advisory with no patched version is never counted as fixed.

  • What happens if I apply them?

    Simulates the result without changing anything, then writes the overrides JSON and the issue text.

Every fix is labelled by how risky it is to apply

So the cheap, safe wins come first and the breaking changes are never a surprise.

Refresh
The fixed version already satisfies every package that requires it. Update and you’re done.
Override
Same major version, but a parent pins the old one. Needs an overrides entry.
Breaking
A major version bump, or no fix exists. Plan time to test it.
